# 🎓 Student Score Tracker

A simple web application that displays student scores, determines pass/fail status, and provides a summary of results. Built using HTML, Tailwind CSS, and JavaScript.

---

## 🚀 Features

- Displays a list of students and their scores
- Automatically highlights:
  - 🟢 Passed students (50 and above)
  - 🔴 Failed students (below 50)
- Shows total number of students who passed
- change button to switch between:
  - All students
  - Passed students only
- Clean and responsive UI using Tailwind CSS

---

## 🛠️ Built With

- HTML5
- Tailwind CSS
- JavaScript (Vanilla)

---

## 📂 How to Run

1. Clone or download this repository
2. Open the project folder
3. Run `index.html` in any web browser
